## 2026-11-06: 统一渲染迁移与逐帧导出

地图标注路径、绘制草稿与路线海拔曲线接入共享 GPU 图层；新缓冲就绪后交接，设备错误时恢复旧绘制。地点标签从 Scene 读取几何并使用引擎投影，现有文字布局和编辑手柄保留。地图、时间指标与海拔交互使用统一拾取入口。

2026-11-07 在 macOS 终端运行 `check:picking:gpu`，实际 DPR 1、2、3 三轮均通过。覆盖 18 万点拾取、跨日期变更线、离屏首帧尺寸与像素、标注显隐和海拔图回退。测试主动触发 WebGL 上下文丢失以验证回退。

时间轴速度曲线、面积填充和海拔剖面由共享 GPU 图层绘制。设备错误时使用同一份曲线数据走 Canvas 回退，移除 ECharts 依赖和 SVG 曲线。面板保留半透明底色，GPU 接管时停用背景模糊，避免曲线被一起模糊。

时间轴底部的足迹和照片密度条与悬停提示共用分桶结果。地图照片点和地理足迹密度接入共享 GPU 图层。地理足迹沿用 `FootprintDensityPass` 的浮点累加、曝光和合成，停在同一视角时复用已累加的纹理。HDR 模式及设备错误使用原地图绘制。标注编辑手柄由共享图层绘制，拖拽沿用 MapLibre 的交互目标，整世界视角使用原手柄绘制。

2026-11-07 在 macOS 终端复跑 `check:picking:gpu`，DPR 1、2、3 三轮全部通过，覆盖时间轴曲线与面积填充、两条密度条的颜色和边界、地图照片点显隐，以及地理足迹的跨经线、重复覆盖和点线切换。编辑手柄像素和新曲线回退断言待复跑。剩余迁移包括 GPU 文字、底图与地形、完整场景导出。

## 2026-11-05: 放大后轨迹点连成线

放大到当前视口内相邻打点屏幕间距的中位数超过 8px 时，足迹自动从散点切换为平滑连线；打点间隔超过 5 分钟处自动断段，避免跨区间误连。缩小至中位数 5px 以下恢复散点显示，双阈值滞回防止缩放时频繁闪烁；以中位数而非任意点对为判据，避免个别离群点误触发。

## 2026-11-05: 城市渲染

地图上的建筑按十倍高度叠加到地层上；并新增道路叠加层，按道路分级渲染，宽度随比例尺变化。

建筑瓦片的本地缓存占用上限可在设置中调整。

## 2026-11-05: 底图语言切换

重制底图样式，底图语言支持跟随系统、当地语言、中文、英文四档切换。

## 2026-11-05: 原生滚轮输入（Mac）

新增 macOS 原生滚轮事件通道，向上层上报触控板惯性阶段与精确滚动信息，用于区分触控板与鼠标滚轮，让地图平移和缩放的手感跟手。（其他平台仍未适配）

## 2026-11-04: 标注数据格式重构

内部工程 JSON 的字段收窄为明确的 schema：节点只存二维 WGS84 坐标，路线海拔由应用按地形数据临时采样、不写回工程；空描述、折叠状态等无内容字段不再落盘，KML 的海拔、线宽、外部图标等信息不再导入导出。旧工程读取时自动剥离 sourceKml 等遗留字段。标注面板选中路线时可直接查看沿程地形剖面图，并配套了导入路线的清洗、分类与匿名化脚本。

## 2026-11-04: HDR 输出

新增 macOS 原生显示器能力探测，在支持的屏幕上可开启 HDR 输出，渲染管线走广色域与扩展亮度范围。

## 2026-11-04: 地形高程渲染

地形改为原始高程着色，支持曝光调节并配套地形图例。

## 2026-11-04: 足迹密度图层

足迹新增密度图层，远处显示为散点、近处密集处以 arctan 收敛曲线堆叠，重复经过持续变亮并趋向纯白。

## 2026-11-04: 时间轴指标曲线

时间轴新增速度和打点密度两条指标曲线（密度由连续核密度计算，带宽不随缩放变化），并补充了时间轴手势操作。

## 2026-11-03: Google Earth 标注导入

## 2026-11-02: 自动语音字幕

视频可自动转写字幕：调用本地 whisper.cpp（自动在 .tools 与安装目录查找识别器及 small/base 模型，含 silero VAD），抽取 16kHz 单声道音轨识别生成字幕。编辑器内可逐条修改文本与入点、出点，保存时在视频旁写出 .subtitles.srt 与 .subtitles.json，作为谈话类视频时间压缩的配套工具。


## 2026-11-02: 时间压缩

新增「载入 DJI 视频」入口，支持 mp4 / mov 并探测媒体信息，视频源面板显示轨道构成、DJI 识别结果与可用硬件编码器数量。媒体处理管线自动探测 VideoToolbox、NVENC、Quick Sync 等硬件编码能力，压缩时由 FFmpeg 只重编码主视频、再用 MP4Box 回换容器，完整保留 DJI 的 djmd/dbgi 私有遥测轨、音频、时间码与封面。通过 exiftool 从私有遥测轨抽取逐帧四元数计算镜头角速度，剧烈转动时保持 1×、持续稳定后平滑加速（最高 8×，跨多个时间尺度分析），按倍率轨积分重映射音视频并以 60fps 线性混合输出，倍率轨随成片侧的 .replay.json 保存。
