# 媒体处理与外部工具

## 工具准备

| 功能 | 外部依赖 |
| --- | --- |
| MP4 / MOV 探测 | PATH 中可调用的 ffprobe |
| 编码、音频提取与动态变速 | PATH 中可调用的 ffmpeg；硬件编码还依赖本机硬件与驱动 |
| 保留 DJI 私有轨的压缩 | ffmpeg、ffprobe 与 GPAC MP4Box |
| 自动字幕 / 声音 token | ffmpeg、Apple Silicon、MLX 与本地 Qwen3-ASR / ForcedAligner |

根目录启动流程会优先加入项目本地媒体工具目录，包括 `.tools/ffmpeg-native/bin`、`.tools/ffmpeg` 和现有 `.tools/gpac-package/tmppkg.pkg/Payload/GPAC.app/Contents/MacOS`。也可将对应工具安装到系统 PATH。应用不会自动下载媒体工具或模型。

应用不附带语音模型，首次启动不下载、不默认选择模型。设置页或文字剪辑对话框分别选择已下载的 ASR 与 ForcedAligner，也可单独下载模型、打开模型目录，或添加其他位置的已有 MLX 模型文件夹。可下载 Qwen3-ASR-0.6B / 1.7B 与 Qwen3-ForcedAligner-0.6B 的 8-bit 版本，源为 Hugging Face 的 `mlx-community` 公共仓库；原模型来自 Qwen。仓库、固定版本、文件清单、SHA-256 与手动安装步骤见 [本地语音模型](local-speech-models.md)。

发行包包含 Python / MLX 推理环境，用户只需准备模型文件。开发环境运行 `cd source && npm run setup:speech` 仅准备运行环境；模型放在 `.tools/qwen/models/`。安装包的模型目录为应用数据下的 `local-speech/models/`，也支持选择外部文件夹。模型和生成的运行环境均不进入 Git。

下载与推理独立：内置下载只传输公开源文件、断点续传和校验完整性；手动下载同样可用，不需要安装回执。推理强制使用本地文件。工作进程串行处理任务，30 秒分段转写并对齐，按标点、停顿和长度合成初始短句。结果按原文件与所选模型文件的大小、修改时间缓存在当前会话中，切换模型会清空缓存，双击拆分复用对齐结果；空闲 3 分钟释放模型内存。默认中文转写。ASR 负责“说了什么”，ForcedAligner 负责“这些字在原音的什么时间”；对齐器不会纠正 ASR 的错字，边界仍需试听校对。

## 界面操作

「载入 DJI 视频」读取 MP4 / MOV 并显示视频、音频与 DJI 元数据轨信息。「时间压缩 → 谈话类 · 字幕轨」打开字幕编辑器，可识别人声、修改字幕并保存为 JSON 和 SRT。识别在本地运行。

压缩、骑行姿态分析和动态变速已存在于媒体模块；完整任务配置界面尚未接入。侧栏「输出目标」等占位内容不代表可以直接创建全部任务。

## 压缩与轨道保留

普通 DJI 压缩使用两阶段流程：FFmpeg 只重编码主视频轨，MP4Box 再将新视频轨替换回原容器，逐样本保留 djmd、dbgi 私有遥测轨，以及原始音频、时间码和缩略图轨。不要用普通 FFmpeg 重封装替代该流程并假定所有 DJI 轨都被保留。

模块可探测 VideoToolbox、NVENC、Quick Sync、AMF、VAAPI 与 CPU 编码能力；实际使用取决于 FFmpeg 构建及本机可用编码器。

## 时间压缩

骑行类逻辑对 DJI 逐帧四元数进行多尺度累计旋转分析，生成随时间变化的播放倍率轨。动态变速按倍率积分重映射视频与音频，并以 60 fps 线性混合采样输出。

变速成片不会直接挂载原时长的 DJI 遥测轨。原遥测保留在源数据中，成片旁生成 `.replay.json`，其倍率轨换算到成片时间轴。遥测 sample duration 的同步重写和重新封装尚未完成。

## 透明轨迹叠加

地图工作区的叠加导出独立于上述 DJI 压缩流程，输出 VP9 WebM + Alpha，时间与轨迹保持 1:1。支持 720p / 1080p / 4K、24 / 30 / 60 fps，6 / 12 / 24 / 48 Mbps，按 1 / 5 / 10 / 30 分钟分段。统计信息与小地图可分别关闭；显示小地图时需等待地图就绪。

海拔缺失时无法提供可靠的海拔与坡度，导入字段见 [位置数据格式](data-format.md)。


透明叠加优先使用支持 `libvpx-vp9` 的 FFmpeg 逐帧导出。选择保存位置后，各分段连续写入；渲染耗时不会改变输出帧率或跳过轨迹时刻。不同 FFmpeg 版本支持的编码器可能不同，应用会在本地工具与 PATH 中查找可用版本；找不到时保留实时录制方式。

逐帧导出取消后会清除当前未完成分段，已完成的分段保留。遇到同名文件会自动添加序号。导出开始时固定轨迹、标注与图层开关，之后的地图操作不会改变正在生成的视频。

逐帧导出的小地图标注通过共享 Scene 和 AnnotationLayer 离屏绘制，等待 GPU 帧完成后与道路底图合成；未提交的绘制草稿不进入成片。地图与标注按输出分辨率设定像素密度，不跟随显示器的 Retina 倍率。道路与近期路线仍使用导航地图，统计文字与罗盘仍使用 Canvas，完整地形场景尚未接入这条导出路径。

## 按声音 token 剪辑

在「视频与导出」→「时间压缩」点击「文字剪辑音频」。导入录音或带音轨的视频后，会在本地识别成粗分的短句 token，显示在一个像文本编辑器一样的连续页面中。每个 token 绑定一段原音，未识别出文字的原音也会保留。

拖选或使用 ⌘/Ctrl+A 全选，⌘/Ctrl+C 复制、X 剪切、V 粘贴，Backspace / Delete 删除。复制后的每一次出现都独立参与音频拼接，可以重复同一段声音。支持撤销和重做。普通文字没有原音绑定，字幕文字可在点击 token 后的属性区校对。

在序列光标处输入以下内容，再按回车即可插入控制 token；也可以用工具栏插入：

| 写法 | 含义 |
| --- | --- |
| `0.2s` | 插入 0.2 秒合成静音。 |
| `+0.1s` | 取前一个 token 结束后 0.1 秒的原音，接在这里。 |
| `0.3s+` | 取后一个 token 开始前 0.3 秒的原音，接在这里。 |

延伸 token 按当前位置的相邻片段取音，复制或移动后会重新计算。不能向静音取原音；缺少相邻片段、循环依赖或超出原素材范围时，页面会提示，调整后才可试听和导出。延伸会保留相邻 token 本身，若与其他片段重叠，重叠的原音会按序列重复播放。

双击语音 token，会使用本地 ForcedAligner 的词/字时间戳继续拆分（中文通常可细到单字）。拆分保留原片段的完整时长，不会把未标注文字的间隙自动丢弃。识别边界可能需要试听校对；已到最细时间戳时，可在属性区「手动指定切点」继续分割。双击静音或延伸 token 会把其时长一分为二。

「试听整个序列」按当前顺序播放声音、静音与延伸片段。「导出音频」生成 WAV、按成片时间重算的 SRT 和 `.audio-edit.json` 剪辑序列。重新导入同一原音后，点击「恢复剪辑」载入该 JSON，可继续编辑。复制粘贴通过剪贴板保留 token 与原音的绑定，跨应用如丢失该信息，应使用剪辑序列恢复。原素材保留。

编辑区内轻按空格从当前光标位置开始试听，再轻按空格暂停。按住空格超过约 0.25 秒开始麦克风录音，松开结束并将录音插入光标处；首次使用需允许麦克风。尚未导入素材时也可直接按住空格开始一个录音工程。授权未完成就松键会取消这次录音；失去窗口焦点会结束正在进行的录音。录音保存在应用数据目录，不会因清理缓存丢失，参与复制、拆分、试听和导出。输入中的合法控制字符串只按回车转成 token，空格不提交输入。
