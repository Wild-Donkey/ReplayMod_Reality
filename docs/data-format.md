# 位置 CSV 格式

通过「载入数据源」选择带表头的 CSV。解析器支持 UTF-8 BOM，跳过空行并裁剪字段空白。

| 字段 | 要求与含义 |
| --- | --- |
| `dataTime` | 必需，Unix 时间戳，单位为秒；内部转换为毫秒 |
| `longitude` | 必需，经度，范围 −180 至 180 |
| `latitude` | 必需，纬度，范围 −90 至 90 |
| `stepType` | 建议提供；1 为照片位置，其他值按足迹处理，通常使用 0 |
| `altitude` | 可选，海拔米；也接受 elevation、height、alt，按此顺序取首个存在的字段 |

最小示例：

```csv
dataTime,longitude,latitude,stepType,altitude
1700000000,116.397,39.908,0,45
1700000060,116.398,39.909,1,46
```

无法解析或越界的坐标、空白或非数字时间戳会被跳过；缺失必需列可能导致导入失败。海拔空白或无效时保留缺失状态，不当作零海拔。其他输入列不保证进入当前 PointDataset；速度和坡度显示由位置、时间及海拔派生。

## 自动读取与合并

源码工作区会从 `RawData/footprint/` 寻找最近修改的主 CSV，与同目录 PhotoData CSV 合并。照片点按时间戳与保留六位小数的经纬度组合去重，不代表对全部足迹做异常点清洗。读取后足迹、照片及时间轴数据按时间排序。

原始数据放在 `RawData/`，不提交 Git。不要把某台机器上的点数、日期范围或经纬度范围当作导入格式限制。

## 打点海拔与地面高程

应用中存在两个相互独立的海拔来源，比较前必须区分：

- 打点海拔：CSV 中设备记录的海拔（`altitude` 等字段），随每个时间线点保存，基准取决于采集设备和数据源。
- 地面高程：由 MapTiler `terrain-rgb-v2` 地形服务临时采样得到，采样层级上限为 z12；同一点位所在瓦片只下载解码一次，结果不写回任何工程或数据集。

两个来源的高程基准可能存在系统性偏差，直接相减的结果包含该偏差。

地面高程当前有三种采样方式，都属于临时采样：

- 选中标注路线时，沿路线等距抽取最多 500 个点生成里程海拔图；
- 地图上移动指针时，对指针位置单点采样；
- 飞行点筛查对整条时间线逐点采样，不受 500 点上限约束。

### 飞行点筛查

离地高度按 `打点海拔 − 地面高程` 逐点计算，严格大于 100 米判定为飞行点。建筑高度有意排除在地面高程之外，100 米阈值也高于常规建筑与上述基准偏差。打点海拔或地面高程缺失（`NaN`）的点标记为不可判定，既不算飞行也不算地面。

筛查结果与时间线等长、逐点对齐，包含：每个点的两种海拔、离地高度与判定标志，全部飞行点索引、最大离地高度、由相邻飞行点合并出的连续区段（含区段时长与最大离地高度），以及可直接供图层或时间线过滤使用的 0/1 掩码。

当前只提供识别与筛选结果，地图高亮、时间线过滤等界面消费尚未接入，显示层重构后再使用这些索引、区段与掩码。

## 坐标系与插值

经纬度数值本身无法判断 WGS84 或 GCJ-02。当前版本不会自动识别或转换，应在导入前确认与底图一致；中国大陆数据需要人工检查偏移。

时间轴在相邻点间线性插值。长时间缺测时，插值不代表真实经过的路线。当前没有完整的异常点清理、按间隔分段、抽稀或 GPX / FIT 导出流程。
