# 本地存储、缓存与恢复

「设置 → 统一磁盘缓存」显示当前占用和总容量上限，默认 4 GiB。地图样式、瓦片、地形、机场数据、建筑 LOD、解析后的轨迹快照和飞行筛查进度共用此预算。超过上限时优先淘汰最久未使用的条目，使用顺序会跨重启保留。地图资源的刷新周期与淘汰独立，刷新失败时可继续使用磁盘上已有的条目。

缓存位于应用数据目录下的 `resource-cache-v1/`。可通过设置中的「打开缓存目录」查看实际路径。首次启动会迁移旧系统缓存目录和更早版本应用数据目录中的地图及轨迹缓存。建筑 LOD 会从磁盘恢复最近保留的建筑轮廓，建筑内存上限控制单个窗口加载和保留的轮廓数量。Chromium 的 HTTP 缓存已停用，GPU 缓存继续由渲染引擎管理。

用户存档和缓存分别保存。应用数据目录（macOS 为 `~/Library/Application Support/ReplayMod Reality/`）中的 `user-archive.json` 保存地图配置、工作区、最近打开的文件和已确认航班，`annotations.json` 保存地图标注。`config.json` 和 `state-v1/` 用于兼容旧版本。正常关闭时会补存工作区并等待已排队的缓存写入。

轨迹快照按源文件路径、大小和修改时间匹配，并保留缺失海拔的 `NaN`。最近打开的源文件暂时不可用时，如果对应快照仍在，可用它恢复轨迹。视频内容保留在原位置，恢复时仍需访问源文件。

退出应用后可删除 `resource-cache-v1/` 以重置应用缓存。工作区、地图密钥、标注和已确认航班会保留。
